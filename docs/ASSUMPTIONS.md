# Assumptions

- Default currency is EGP.
- Default timezone is Africa/Cairo.
- Supported locales are English and Arabic.
- Local development uses Supabase CLI.
- Production email delivery uses Supabase Auth custom SMTP backed by Resend.
- Production app links/universal links require a future verified domain.
- This release does not include bank sync, open banking, tax calculation, or employer payroll management.
